# PKA No Oficial Wiki

Primera versión de una wiki comunitaria en español para PokeAlliance.

## Publicar en Cloudflare Pages

1. Sube **todo el contenido de esta carpeta** a un repositorio de GitHub.
2. En Cloudflare Pages selecciona el repositorio.
3. Production branch: `main`.
4. Framework preset: `None`.
5. Build command: dejar vacío.
6. Build output directory: `public`.
7. Guarda y despliega.

## Contenido

Los datos fueron organizados a partir de `Pokedex Pública PokeAlliance (By Mts Vitor)`. Se omitieron hojas auxiliares/de búsqueda y una hoja de ejemplo comercial (`Planilha1`) que no corresponde al juego. Los nombres de objetos, Pokémon y términos del juego se mantienen cuando es útil para buscarlos exactamente dentro de PokeAlliance.

## Aviso

Proyecto no oficial, no afiliado ni respaldado por PokeAlliance. Los valores pueden cambiar con actualizaciones del juego.


## Actualización de guías

Esta versión añade una sección de Guías con quests, rotaciones y sistemas explicados en español, además de corregir el encabezado sticky de las tablas para que no cubra la primera fila. Las guías se reorganizaron a partir de material comunitario; no son copias literales de los HTML de referencia.
