# Actualización UX — 13/09/2026

Se mejoró la navegación general de la PKA No Oficial Wiki sin eliminar el contenido existente.

## Cambios principales

- Navegación principal reorganizada en seis grupos: Pokédex, Mundo, Progresión, Guías, Herramientas y Comunidad.
- Submenús desplegables para reducir saturación del header.
- Buscador global disponible desde cualquier página.
- Atajo de teclado Ctrl+K / Cmd+K para abrir el buscador.
- Resultados agrupados por Pokémon, secciones/guías y NPCs.
- Las fichas Pokémon muestran accesos relacionados a Drops, Localizaciones, Tasks, Tier y otras secciones disponibles.
- Los enlaces relacionados pueden enviar `?q=` a páginas con buscador local para intentar abrirlas ya filtradas.
- Diseño responsivo para escritorio y móvil.
- Índice ligero de páginas y relaciones Pokémon generado en `public/data/`.

## Archivos principales modificados

- `public/assets/app.js`
- `public/assets/styles.css`

## Archivos añadidos

- `public/data/search-pages.json`
- `public/data/search-pokemon-relations.json`

No se eliminó ninguna página ni se cambió la estructura de URLs existente.

## Segunda mejora: tablas visuales

Se añadió una capa visual para las páginas con mayor densidad de tablas (Achievements, Gamepass, NPC Jully, Experiencia, Entrenamiento, Comandos, Brokes, Hazard, Cupones, Gyms y otras páginas comparativas/listados).

- Vista por defecto en tarjetas para facilitar lectura y escaneo.
- Los encabezados de columna se reutilizan como etiquetas dentro de cada tarjeta.
- Tablas cortas de 2 columnas se muestran como bloques de datos/resumen.
- Botón `Tabla / Tarjetas` para cambiar de vista sin perder la tabla original.
- La preferencia queda guardada en `localStorage` (`pka-table-view`).
- En móvil las tarjetas pasan automáticamente a una sola columna.
- Se conserva el HTML semántico original y no se eliminaron datos.


## Auditoría completa de tablas
- Catálogos/listados simples pasan a tarjetas.
- Jully queda siempre como catálogo visual y ya no hereda una preferencia global de tabla.
- Comparativas y matrices de varias columnas se mantienen como tablas.
- Listados visuales largos tienen búsqueda local.
- La preferencia Tabla/Tarjetas se guarda por página.
