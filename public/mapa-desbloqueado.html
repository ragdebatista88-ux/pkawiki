Instalación

¿Cómo importar el mapa?

Son solo dos pasos. Puedes hacer clic en cada imagen para verla en grande.

1

Abre Backup / Restore

Abre el Client, haz clic en la rueda de ajustes ⚙️ y selecciona Backup / Restore.

2

Importa el minimapa

En la sección MINIMAP, haz clic en Import minimap y selecciona el archivo minimap854.otmm que descargaste.

Importante: esta opción importa únicamente el minimapa. No necesitas usar Import settings.
